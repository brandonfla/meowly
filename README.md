# Meowly

A website dreamed up by Nora.

Meowly is a playful guide to making a cat like you: seven gentle tips, four body-language signs, and a few habits to avoid, set in a sunset sky with a cat that rides its cloud down the page.

Live at https://brandonfla.github.io/meowly/

## Run it

It's a static site with no build step. Open `index.html`, or serve the folder:

```bash
python3 -m http.server 5317
```

Photographs are from Wikimedia Commons; credits are listed in the site footer.
